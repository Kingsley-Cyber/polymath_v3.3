## Data flow

The Pinion API reads incoming events from the Larkspur Queue. The Pinion API sends normalized
batches to the Sable Index. Quartzline migrated its archives to the Vaultstone store in 2029.
Vaultstone is a cold-storage service written in Rust. The Larkspur Queue is read by the Pinion API
whenever a backlog forms.
