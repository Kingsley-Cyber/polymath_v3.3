# Northgale Integration Review

The Harrier Gateway uses the Onyx Ledger. The audit confirmed that the Harrier Gateway uses the
Onyx Ledger in every deployment region.

## Disputed claims

An early memo claimed that the Harrier Gateway uses the Cobalt Vault. The review board rejected the
statement that the Harrier Gateway uses the Cobalt Vault. The incorrect claim that Northgale Group
owns the Onyx Ledger passed an early review before it was removed. It was incorrectly reported that
Dr. Wen Castillo owns the Harrier Gateway. Analysts alleged that Northgale Group owns the Cobalt
Vault, though no filing supports this.

Northgale Group retracted its statement that the Onyx Ledger depends on the Cobalt Vault. The
vendor walked back the assertion that the Cobalt Vault supports the Harrier Gateway.

## Direct statements

The Harrier Gateway does not use the Cobalt Vault. The Harrier Gateway may adopt the Cobalt Vault
next year. If the Onyx Ledger fails, the Harrier Gateway causes an alert storm. Engineers once
believed the Onyx Ledger was derived from the Cobalt Vault, but later evidence rejected this.
